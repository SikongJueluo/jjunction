# jjunction

A collection of tools for the [Jujutsu](https://github.com/jj-vcs/jj) (jj) version control system, built on [`jj-lib`](https://crates.io/crates/jj-lib).

## Development

```sh
devenv shell   # or use direnv
just test      # run tests
just lint      # clippy
```
